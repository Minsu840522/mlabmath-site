# mlabmath-site

**mlabmath.com** 맨 앞 주소에 올라가는 홍보용 정적 페이지 — "중대부고 1학년 수학 내신 자료집".
개념상상 대치관 박민수T 반의 외부 신규 학부모 유입이 목적이며, 검색 엔진과 AI 검색(챗지피티·클로드)이
읽고 인용할 수 있도록 **글자 중심 + 구조화 표기(JSON-LD)** 로 만든다. 상담은 학원 전화(02-567-0508)로 유도.

## 구성
- `index.html` — 한 장짜리 페이지(출제 경향 · 이번 시험 분석 · 수업 문제 비교 · 기말 대비 · FAQ · 수업 안내)
- `assets/style.css` — 스타일(리포트와 같은 네이비/블루 톤)
- `assets/img/` — 시험 문제 ↔ 수업 문제 비교 이미지(`중대부고 기출분석/1학년/리포트_2026-2학기중간/images` 사본)
- `robots.txt` · `sitemap.xml` — 검색/AI 로봇 허용과 사이트맵
- `CNAME` — GitHub Pages 사용자 지정 도메인(`mlabmath.com`)

## 호스팅
GitHub Pages(저장소 `Minsu840522/mlabmath-site`, `main` 브랜치 루트). 하위 주소(`sim.`·`autobook.`·`qa.`·`latex.`)는 NAS 그대로.
DNS 는 클라우드플레어 — 맨 앞 주소 `mlabmath.com` 을 `minsu840522.github.io` 로 CNAME(평탄화), `www` 도 같이.

## 갱신 절차
1. 시험 끝나면 `중대부고 기출분석/1학년/` 의 분석 문서와 리포트를 근거로 `index.html` 의 해당 절을 고친다.
2. 머리말의 `dateModified`·작성일·`sitemap.xml` 의 `lastmod` 를 갱신한다.
3. 커밋·푸시하면 1~2분 뒤 사이트에 반영된다.
